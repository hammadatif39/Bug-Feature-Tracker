# Bug & Feature Tracker

## 1. Project Description
The Bug & Feature Tracker is a simple Python terminal application that allows users to record software issues and feature requests, view the recorded entries, and display a summary of the tracker. 

## 2. Features
* **Add an Entry:** Users can record a title, type (Bug/Feature), priority, and status.
* **View All Entries:** Displays all recorded bugs and features in a readable format.
* **Display Summary Statistics:** Shows the total number of entries, broken down by bugs, features, open, and resolved statuses.
* **Menu and Navigation:** Provides a simple terminal menu to navigate the application.
* **Input Validation:** Prevents the program from crashing by handling empty titles and invalid menu choices.

## 3. Technologies Used
* Python
* Git CLI
* GitHub

## 4. How to Run
To run the application, open your terminal in the project directory and execute:
python main.py
